# Fonts

Drop your licensed Spotify Circular `.woff2` files here with these exact names:

- `CircularSpUI-Book.woff2`   → weight 400 (body text)
- `CircularSpUI-Medium.woff2` → weight 500 (titles, active nav)
- `CircularSpUI-Bold.woff2`   → weight 700 (headings, "Listen again")

Spotify's real UI font is **Circular** (by Lineto), branded internally as
"CircularSpUI" / "CircularSp". Only add files you are licensed to use — they
are NOT redistributed with this repo.

`.woff` or `.ttf` also work; if you use a different format/name, tell me and
I'll adjust the @font-face `src` in src/spotify.css.
