# Project rules

## Git commits
- Always commit as `nklmarch17@gmail.com`. Before the first commit in this repo, run:
  `git config user.email "nklmarch17@gmail.com"`
- Commit after each small, incremental change — don't batch many unrelated changes into one commit.
- Use short Conventional Commits messages: `type: summary` (≤50 chars, imperative mood).
  Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`, `build`, `ci`, `perf`.
  Examples: `feat: add login form`, `fix: handle null user`, `refactor: extract parser`.
